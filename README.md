## Playable Demo

Download the demo from the [Releases](https://github.com/dylogaming/CombatComponent/releases) page. Unzip and run CC_Demo.exe.

- F1 Movement, F2 Enemies, F3 Takedowns, F4 Weapons
- Escape opens the pause menu
- Windows 10 or 11, 64 bit
